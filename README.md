# AI-помощник для подготовки товарных описаний

Автоматический генератор SEO-карточек. Использует локальную нейросеть Ollama + Qwen 3.5.

## Требования

- Python 3.8+
- Ollama (установлена и запущена)
- Модель `qwen3.5:4b`
- Минимум 8 ГБ RAM

## Установка

1. Клонируй репозиторий
2. Установи зависимости:
```bash
pip install -r requirements.txt
```
3. Скачай модель:
```bash
ollama run qwen3.5:4b
```
4. Создай и настрой `.env`:
```bash
cp .env.example .env
```
5. Убедись, что Ollama запущена (иконка ламы в трее)
6. Запусти скрипт:
```bash
python main.py
```
7. Результат в `output.json`

# Настройки (.env)

| Параметр | Описание | По умолчанию                          |
|----------|----------|---------------------------------------|
| `OLLAMA_URL` | URL локального API Ollama | `http://localhost:11434/api/generate` |
| `MODEL_NAME` | Название модели | `qwen3.5:4b`                          |
| `TIMEOUT` | Таймаут запроса в секундах | `120`                                 |
| `TEMPERATURE` | Температура генерации | `0.1`                                 |
| `NUM_CTX` | Размер контекста в токенах | `8192`                                |
